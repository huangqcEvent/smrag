# 登录页中英透镜交互设计

## 目标

将现有渐变卡片式登录页重构为具有品牌识别度的全屏登录场景。页面默认显示中文；鼠标移动时，以光标为圆心显示英文视觉层，形成局部语言切换效果。登录表单只占页面较小区域，核心登录行为、错误处理和权限逻辑保持不变。

## 视觉方向

页面使用暖白色背景与深墨色文字，保留项目现有青绿色作为操作色。背景铺设低对比度的 `SMRAG` 字母纹理，形成识别度但不干扰输入。

主要内容包括：

- 左上角：项目品牌标识与“私募 AI 专家”。
- 中央偏左：中文主标题“你好，我是私募 AI 专家”。
- 右下侧：约 360px 宽的紧凑登录面板。
- 中文表单文案：“账号”“密码”“进入系统”。

英文视觉层与中文层完全对齐，使用以下文案：

- 主标题：`HELLO, I'M SMRAG`
- 表单标签：`ACCOUNT`、`PASSWORD`
- 登录按钮：`ENTER`

透镜区域使用深墨色背景、暖白色文字和低对比度字母纹理。页面不使用渐变文字、装饰性玻璃拟态或弹跳动画。

## 页面结构

登录页由两个重叠的场景层组成：

1. 中文交互层：包含唯一一套真实表单，负责输入、点击、键盘导航、密码显示和提交。
2. 英文视觉层：作为中文层的对齐副本，仅用于透镜内展示，设置 `aria-hidden="true"` 且不接收鼠标或键盘事件。

英文层同步中文层的账号内容、密码掩码、焦点、密码显示状态和加载状态。页面不得创建第二次登录提交，也不得让视觉副本进入无障碍树。

## 透镜交互

桌面指针设备上，页面监听指针进入、移动和离开：

- 进入时，透镜以光标为圆心平滑展开。
- 移动时，仅更新页面级 CSS 坐标变量。
- 英文视觉层通过 `clip-path: circle(...)` 显示。
- 离开时，透镜平滑收起。
- 透镜目标直径约 420px，可根据视口宽度限制在合理范围。

动画使用快速、克制的 ease-out 曲线，不使用弹跳或弹性效果。坐标更新应通过 `requestAnimationFrame` 合并，避免每个指针事件触发 Vue 组件重渲染。

## 表单行为

现有登录行为保持不变：

- 用户名和密码为空时显示固定中文校验提示。
- 登录中按钮不可重复提交，并显示加载状态。
- 登录成功后按原逻辑跳转。
- 登录失败继续使用统一安全错误通知，不展示 Axios、HTTP、Java 或数据库技术信息。
- 密码显示切换、浏览器自动填充和回车提交继续可用。

视觉副本必须反映真实表单状态，但不得拥有独立业务状态。

## 响应式与无障碍

触摸设备、窄屏设备和 `prefers-reduced-motion: reduce` 环境禁用透镜，固定显示中文交互层：

- 主标题缩小并移到页面上部。
- 登录面板移动到底部居中。
- 背景纹理降低密度，避免遮挡。

真实表单继续使用关联的 `label`、明确的输入类型和自动填充属性。按钮、密码显示开关和输入框保留清晰的 `focus-visible` 状态。英文层使用 `aria-hidden` 和 `pointer-events: none`，不产生重复朗读和焦点。

## 组件边界

登录业务状态继续由 `Login.vue` 管理。新增一个无业务副作用的登录场景展示组件，接收以下状态：

- 当前语言。
- 是否为交互层。
- 用户名、密码显示状态和加载状态。
- 当前聚焦字段。
- 中文层的输入、提交和密码显示事件。

透镜坐标和是否启用由独立的小型组合函数或纯工具管理，以便单独测试。英文层不得直接依赖认证 Store。

## 验证

自动化测试覆盖：

- 中文与英文文案同时存在。
- 页面只有一套可交互表单。
- 英文视觉层不可交互并从无障碍树隐藏。
- 透镜状态能正确处理进入、移动和离开。
- 减少动态效果及非指针设备关闭透镜。
- 现有表单校验、加载和安全错误反馈不回退。

生产构建通过后，在桌面浏览器中检查透镜对齐、输入同步、焦点状态、自动填充和不同视口尺寸；在移动视口检查中文静态降级。

## 非目标

- 不增加真正的语言切换设置或国际化路由。
- 不修改后端登录接口、认证 Store 或权限体系。
- 不为其他页面引入相同透镜效果。
- 不复刻 MiMo 的品牌资产、字体或原始页面代码。
