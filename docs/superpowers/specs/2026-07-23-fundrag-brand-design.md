# FundRAG 品牌命名设计

## 目标

将当前产品名“基金智库”统一替换为“FundRAG”，直接表达基金领域与 RAG 技术属性，同时保留现有登录页的标题透镜交互。

## 品牌文案

- 产品名：`FundRAG`
- 中文登录标题：`你好，我是 FundRAG`
- 英文透镜标题：`HELLO, I'M FUNDRAG`
- 产品定位：`可溯源的基金知识助手`
- 浏览器标题：`FundRAG`

## 替换范围

- 登录页主标题、背景纹理和登录面板辅助文案
- 应用导航栏品牌名及无障碍标签
- 路由生成的浏览器标题与 HTML 默认标题
- 产品说明、项目 README 和相关登录页设计文档
- 品牌一致性自动化测试

## 交互约束

- 仅登录页左侧品牌区域保留圆形中英文透镜效果。
- 登录表单始终保持白底、中文，不随透镜切换。
- 不改变现有登录、鉴权、路由和响应式布局逻辑。

## 验收标准

- 用户可见区域不再出现“基金智库”旧名称。
- 默认标题显示“你好，我是 FundRAG”。
- 圆形透镜内显示“HELLO, I'M FUNDRAG”。
- 登录表单在透镜经过时不变色、不换字。
- 品牌测试、前端完整测试和生产构建全部通过。
