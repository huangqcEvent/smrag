# 基金智库静态登录页设计

## 目标

将登录页收敛为稳定、克制的静态中文入口。页面不再根据鼠标位置变色或切换文案，不保留英文视觉副本，也不展示左上角 Logo。认证、错误提示和跳转逻辑保持不变。

## 视觉结构

- 页面使用近白背景、深色文字和现有青绿色操作色。
- 左侧保留“你好，我是基金智库”主标题、知识工作台说明和低对比度“基金智库”背景纹理。
- 删除左上角品牌标识整组内容，避免与主标题重复。
- 登录面板位于页面右侧并垂直居中，桌面宽度约 `26rem`，增加面板内边距和输入控件高度。
- 页面仅包含中文文案，不创建英文视觉层、圆形遮罩或指针跟随效果。

## 表单行为

- 页面只有一套真实表单。
- 用户名、密码、密码显隐、回车提交、加载态和自动填充继续可用。
- 空值校验、登录成功跳转和统一安全错误提示保持现有行为。
- 表单标签、焦点状态和按钮状态保持清晰可见。

## 响应式

- 宽屏采用左侧说明、右侧表单的布局，表单垂直居中。
- 中小屏降低主标题字号并缩小左右留白，避免标题与表单重叠。
- 窄屏改为上下布局，表单在标题下方居中显示。
- 小高度窗口和高倍率缩放环境允许纵向滚动，不能裁切表单。

## 组件边界

- `Login.vue` 继续管理业务状态和认证流程。
- `LoginScene.vue` 只渲染一套中文场景与真实表单。
- 登录文案集中在 `loginCopy.js`，仅保留实际使用的中文字段。
- 删除指针透镜工具及其测试，避免保留不可达逻辑。

## 验证

- 自动化测试确认页面没有英文层、指针事件和左上角品牌标识。
- 自动化测试确认登录面板右侧垂直居中且尺寸已放大。
- 现有登录校验、错误反馈和跳转测试不回退。
- 在桌面、窄屏和小高度视口进行浏览器检查，并通过生产构建。
