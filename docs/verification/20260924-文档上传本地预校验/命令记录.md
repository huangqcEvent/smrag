## 用例 5：上限口径只有一处（R3）

```bash
rg -n "20971520|20 \* 1024 \* 1024" smrag-web/src
rg -n "\.size" smrag-web/src
rg -n "maxUploadSizeBytes" smrag-core/src/main
```

输出：

```text
smrag-web/src/constants/uploadLimits.js:11:export const MAX_UPLOAD_SIZE_BYTES = 20 * 1024 * 1024
smrag-web/src/utils/uploadGuard.js:20:  const size = Number(file.size)
smrag-core/src/main/java/com/hqc/smrag/config/RagProperties.java:143:    private long maxUploadSizeBytes = 20L * 1024 * 1024;
```

结论：`smrag-web/src` 下上限字面量只出现 1 次；读取文件大小的位置也只有 1 处。
前端 `20 * 1024 * 1024` 与后端 `20L * 1024 * 1024`、`application.yml` 的
`smrag.rag.max-upload-size-bytes: 20971520` 三者一致。
